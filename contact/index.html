For the programs that read DeepStack

The static API at /api/v1/ and the MCP endpoint documented at /mcp/ are free and need no key. A wrong answer from a tool, a file that will not parse, or a rate limit that bites too early is a support request like any other: send the tool name, the arguments and the time, and nothing else.
